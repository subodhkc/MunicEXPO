# Security

## Reporting

To report a security issue in HAIEC, contact the team through
https://www.haiec.com — do not open public issues for vulnerabilities.

## This repository

This is a publication/evidence slice, not the deployable product. The
development-only QA hub (`app/dev/qa-review`) hard-404s outside
`NODE_ENV=development` test mode and is not part of the production surface.
