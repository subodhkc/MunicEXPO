## Interactive product review

- **Login:** https://www.haiec.com/login
- **Email:** `munich-judge@haiec.com`
- **Password:** `Kestrel-Judge-2026`
- **Workspace:** MunichTech Demo

After logging in, open **Judge Review** — the persistent entry at the top of
the Munich Tech group in the sidebar. It runs a guided four-step proof of the
frozen Kestrel evaluation (Result → Visual proof → Release change → Verify)
and deep-links into the exact live surfaces, including the canonical
Release A / Release B comparison.

The workspace contains the real frozen Kestrel evaluation alongside the
demonstration systems — Assurance → Evaluations → the Kestrel report opens
the same REVIEW evaluation shown publicly, with Executive / Technical /
Auditor profiles, Inspect Proof, and the evaluation-bound System
Constellation.

This environment contains demonstration data only.
