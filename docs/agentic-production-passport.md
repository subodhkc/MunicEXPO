# Agentic Production Passport

The evidence and decision context travel with the evaluated release.

A Passport is a portable assurance record for one exact evaluated
system/version: build provenance (source commit, static repository build
identity), capability exposure ladder, consequence paths, human-control and
context bindings, evidence coverage, and frontier declarations.

It is not a certification, compliance certificate, or safety certificate.

Canonical artifact for the frozen Kestrel evaluation:
[`demo/kestrel/passport/agentic-production-passport.json`](../demo/kestrel/passport/agentic-production-passport.json)
(sanitized — internal org/system IDs replaced with public refs; evidence
states unchanged).

Owner: `lib/assurance/agentic-production-passport.ts`.
