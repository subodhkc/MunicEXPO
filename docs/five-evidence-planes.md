# Five Evidence Planes

Five independent questions — not a pipeline, not a maturity ladder:

- **Requested** — what the request asked for
- **Policy Authorized** — what policy/config evidence establishes as permitted
- **Effectively Granted** — what credential evidence establishes
- **Code Capable** — what source evidence establishes the code can do
- **Observed** — what connected runtime evidence established was observed

`CODE_CAPABLE != OBSERVED` and `CODE_CAPABLE != EFFECTIVELY_GRANTED`. A path
that exists in code is not a path that ran.

For Kestrel, all four authority/runtime planes are honestly `NOT_ASSESSED` —
the static evaluation established Code Capable 44/44 and nothing beyond. That
is the evidence model working as designed, not a limitation of the report.
