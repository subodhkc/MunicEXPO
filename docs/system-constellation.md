# System Constellation

The Constellation projects what the AI system can reach and cause: the
evidence-backed paths around the agent, which controls sit on those paths,
and where the evidence ends.

- Evaluation snapshot vs. current view are separate bases — never blurred.
- Graph edges are evidence relations, not observed execution.
- The presentation is consequence-first: mutating effects lead.
- Unknown and bounded states are rendered as unknown — not as green checks.

Owner: `lib/topology/` — topology projector + presentation projection.
