# Judge — Start Here

**The problem:** What can your AI actually cause?

**60-second path:**

1. **Open the live demo** (no login):
   [Kestrel Assurance Report](https://www.haiec.com/sample-reports/kestrel)
   → decision **REVIEW**, 44 consequential paths on a real repository.

2. **Open the Constellation:**
   [Kestrel System Constellation](https://www.haiec.com/sample-reports/kestrel/constellation)
   → select the **ORDER RECORD WRITE** path. One chain:
   `Agent → capability → handler → operation → consequence`.

3. **Open Inspect Proof** on that path — source-backed continuity.

4. **Look at the five planes:** Requested · Policy Authorized ·
   Effectively Granted · Code Capable · Observed.
   Code Capable = 44/44; the other four are honestly `NOT_ASSESSED`.

5. **See where proof stops** — the Evidence Frontier lists what the
   evaluation could not establish (555 items). That's the product's point:
   it shows where the proof ends.

6. **Verify the evidence pack locally** (Node, no dependencies):
   ```
   node competition/verify-evidence.mjs
   ```
   25 checks: artifact hashes, decision, path count, plane states,
   source/evaluation bindings.

7. **Optional interactive review** — see [`JUDGE-ACCESS.md`](JUDGE-ACCESS.md)
   for the MunichTech Demo workspace (password in private judging
   instructions). *If a welcome tour appears on first login, click "Skip
   tour".*

8. **Originality** — [`ORIGINALITY.md`](ORIGINALITY.md): every capability is
   mapped to its real Git commit and date.
