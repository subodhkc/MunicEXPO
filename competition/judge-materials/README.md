# MunichTech Judge Materials

These files are a **frozen competition snapshot** of selected judge-facing
materials from the MunichTech final submission package.

Canonical live submission folder:
https://drive.google.com/drive/folders/1OZzt-FQ5OikApRYyjqi_9vnoEvhsH4Xd

- The PPTX decks are bundled so the repository can be reviewed offline.
- The PDF files are frozen exports of supporting judge material.
- Live product links remain canonical for interactive behavior.
- Evidence truth does not come from slide copy. Canonical technical evidence
  lives under [`demo/kestrel/`](../../demo/kestrel/), and release-comparison
  evidence lives in the sanitized
  [A/B projection](../../demo/kestrel/evidence/kestrel-compare.public.json).
- [`../verify-evidence.mjs`](../verify-evidence.mjs) verifies the published
  evidence artifacts.
- `SHA256SUMS.txt` is file integrity for this snapshot only — it is not part
  of the Kestrel assurance evidence manifest.
- The published demo credential is intentional and grants access only to the
  MunichTech demonstration workspace.
